Тест семи сигналов: оборотов ДВС, тока и SOC батареи, двух температур батареи и температур переднего/заднего моторов. В версии LASS машины эти ID не поддерживаются; новый тест обращается к установленному Android Car.

Как проверить в машине

  1. Установите APK поверх предыдущего L7 Lab.
  2. Откройте «Диагностика» → «Показатели машины · проверка».
  3. Нажмите «Проверить показатели на 30 секунд».
  4. Нажмите Home, чтобы посмотреть нашу карточку.
  5. После теста нажмите «Сохранить архив чтения». Передайте l7lab-telemetry-….zip из Download/L7Lab для разбора.

Числовые данные на машине ещё не подтверждены. Тест показывает выданные разрешения и точные ошибки сервиса, если доступ закрыт. Объявление разрешений в APK не выдаёт системные привилегии. Недоступные и устаревшие значения показаны прочерками. Только чтение семи сигналов, автоматическая остановка через 30 секунд.

Небольшой ZIP содержит отчёт, сведения о разрешениях и версиях служб. APK служб повторно не копируются. Команды открытия стекла в этой сборке не отправляются. «Вернуть демо-счётчик в карточку» возвращает прежний режим.
