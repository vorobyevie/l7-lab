# L7 Lab downloads

0.1.5: краткий тест счётчика поверх отдельного дисплея-кандидата HUD. Только явная кнопка, прозрачное окно 170×72, без перехвата касаний/фокуса, автоматическое удаление через 10сек. Требуется SYSTEM_ALERT_WINDOW, выдаётся обычным системным экраном. Нет запуска Activity на HUD, команд службам автомобиля или изменения штатного HUD.

На стоящем автомобиле: установить поверх → «Диагностика» → «Диагностика HUD» → «Разрешить поверх приложений» → вернуться → «Показать счётчик на 10 секунд». Кнопка «Убрать счётчик сейчас» убирает окно раньше. Ошибки создания отображаются на экране теста.

Кандидат выбирается по единственному доступному экрану 800×480/160dpi из отчёта владельца и разметки HUD шириной 800dp. Физическое назначение и видимость на стекле ещё нужно подтвердить. Реальный WindowManager и скриншоты дополнительного дисплея эмулятора проверены: счётчик обновляется, окно убирается по таймеру, кнопке и отключению дисплея.

На странице только собственные APK; архивы, системные APK/JAR и исследовательские материалы остаются локально.
