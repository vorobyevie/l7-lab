# L7 Lab

Скачать: https://vorobyevie.github.io/l7-lab/

Версия0.1.12 исправляет отображение семи показателей по реальному архиву владельца. Поддержан проверенный OEM-код области; время измерения и время получения ответа разделены. При давнем измерении показан возраст, при отсутствии новых ответов число скрывается.

Чтение запускается вручную на30секунд: Диагностика → Показатели машины · проверка. Новых заявок в кэш CarSupport нет. Команды управления автомобилем не отправляются. После проверки — Сохранить архив чтения, ZIP в Download/L7Lab.

Доставка всех семи показателей в машине подтверждена на0.1.11. Отображение новойверсией и единицы нужно сверить с LiDashboard. Root/системныеправа неиспользуются. В APK нет vendor-программ, тестовыхклассов или данныхвладельца. Контрольнаясумма: SHA256SUMS.txt.
