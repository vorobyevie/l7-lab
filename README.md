# L7 Lab · Силовая установка

Скачать APK: https://vorobyevie.github.io/l7-lab/

Версия 0.2.0: светлая панель по образцу владельца, общий дизайн в приложении и нативной карточке Li Auto. Запас хода, ВБ, обороты, температуры, шины и климат. Семь основных сигналов подтверждены на машине; дополнительные 19 и новый дизайн пока проверены в эмуляторе.

Установить поверх текущего L7 Lab, открыть приложение, вернуться на главный экран. При необходимости добавить карточку кнопкой «На главный экран». Обновление продолжается в фоне с уведомлением и кнопкой остановки. «Сохранить отчёт» пишет ZIP в Download/L7Lab без остановки чтения.

Запросы чтения ограничены семью в секунду. Никаких новых регистраций в кэше, команд управления или выдачи системных прав. Нет доступа к интернету. Неизвестные и устаревшие значения обозначены прочерками. Давление переводится из кПа в бар и требует проверки единиц в машине.

В этом репозитории только собственный APK, страница скачивания и сведения о версии. Исходные архивы владельца, программы сторонних разработчиков, тестовые fixture и ключи не публикуются. SHA256SUMS.txt и version.json содержат контрольную сумму.
