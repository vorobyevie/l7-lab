# L7 Lab 0.7.1 · испытания в автомобиле приостановлены

[Скачать APK для диагностики нашего приложения и эмулятора](https://vorobyevie.github.io/l7-lab/L7Lab-0.7.1-debug.apk).

Причина сообщения о перезапуске нескольких экранов ещё не установлена. На Li Auto временно отключены чтение показателей, полный обзор параметров, загрузка/распознавание речи, добавление карточки и тест HUD. Можно просматривать сохранённые данные, сохранить отчёт и убрать карточку. Защита применяется к LI_AUTO/LIXIANG или модели HU_SS*. Это временное ограничение до разбора системного сбоя.

В старой версии остановите показатели, затем «Диагностика» → «Карточка» → «Убрать нашу карточку с главного экрана». Принудительно остановите L7 Lab в настройках Android. Проверять повторение системного сбоя на ходу нельзя.

В 0.7.1 «Сохранить отчёт» добавляет память, температурный статус Android, uptime и историю завершений только нашего процесса. Это не полный журнал головного устройства и не доказательство причины перезагрузки. Архив остаётся на устройстве в Download/L7Lab.

Оптимизации для дальнейшей проверки в эмуляторе:

- Ручной запуск панели на 5 минут; остановка при выключении экрана, нехватке памяти или сильном перегреве.
- До 3 запросов панели/с, ток приоритетный. Первый полный набор — примерно за 15 секунд. Общий предел конечных диагностических режимов — 7 запросов/с.
- Фильтрация сообщений вне UI и ограниченный контейнер последних ответов вместо неограниченной очереди задач.
- Компактное состояние карточки, сохранённый результат разбора JSON, остановка неактивной карточки, изображения по необходимости, удалён дополнительный GPU-слой.
- Дисковые контрольные точки и снимки Android-виджета — раз в 10 секунд; живая карточка получает обновления раз в секунду.
- Речь выполняется отдельно от панели. Загрузка ограничена до 1 МиБ/с, распознавание использует один поток CPU, модель освобождается после результата.

Проверены: 100000 событий ограниченного контейнера, 10000 сообщений из отдельного UID, пятиминутная сессия с остановкой, все 29 синтетических значений, оригинальный ABI карточки, её остановка/возобновление при смене видимости, обе темы, настоящая русская транскрипция Parakeet, HTTPS-дозагрузка с ограничением скорости и контрольной суммой. Результаты эмулятора не являются проверкой устойчивости автомобиля.

Сохранены пакет com.relix.l7lab, ARM64 и прежняя подпись для обновления. Модель отдельно, 670478772 байта, в APK не включена. Звук не отправляется в интернет. Архивы владельца и программы автомобиля в этот репозиторий не включаются.
