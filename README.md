# L7 Lab downloads

Страница скачивания тестового приложения для центрального экрана Li L7.

В репозитории публикуются страница, собственный APK L7 Lab 0.1.2 и контрольная сумма. Пакеты HudSettings, данные разбора чужих приложений, локальная диагностика и ключи подписи не публикуются.

Android 9+, package `com.relix.l7lab`. Это debug-сборка для проверки установки и интерфейса. Интеграция со штатным главным экраном Lixiang 7.4.1 не реализована.

Страница предназначена для GitHub Pages: ветка `main`, папка `/ (root)`.

В 0.1.1: встроен Noto Sans (SIL OFL 1.1, лицензия внутри APK), заданы интервалы и сглаживание текста; добавлено постоянное сообщение при недоступном закреплении Android-виджета. Интеграции с карточками Li Auto в этой версии по-прежнему нет.

В 0.1.2: локальное сохранение установочных APK главного экрана и CarSupport через «Диагностика» → «Сохранить APK для разбора». Архив создаётся в Download/L7Lab и автоматически никуда не отправляется. Персональные данные приложений не включаются. Виджет к штатному лаунчеру 7.4.1 пока не подключён.
