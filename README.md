# L7 Lab downloads

0.1.8: экспериментальный 30-секундный тест подписки и чтения семи OEM LASS сигналов под обычным UID L7 Lab. Предыдущий тест 0.1.7 в машине подтвердил Binder-соединение и ответы, но все семь ответов были java.lang.String вместо чисел. Числовые данные на машине пока не получены; необходимость подписки — проверяемая гипотеза.

Установить поверх предыдущей версии → Диагностика → Показатели машины · проверка → Проверить показатели на 30 секунд → Home для просмотра нашей карточки. После теста Сохранить архив чтения → передать Download/L7Lab/l7lab-telemetry-<timestamp>.zip для разбора.

Подписка снимается при остановке/таймере; только семь read/observer сигналов, без setter, автозапуска и выдачи привилегий. Недоступные/устаревшие значения скрываются. Строковый NULL сохраняется как диагностический результат и не превращается в число. Последний отчёт сохраняется локально.

Архив создаётся только по кнопке: собственный отчёт и установочные APK штатных LASS/com.android.car, если доступны, с версиями и SHA-256. Частные данные и настройки служб не копируются. На GitHub архивы и сторонние файлы не публикуются — только собственный APK и страница скачивания.

Локальные тесты используют синтетический сервис в другом UID: get=NULL, числа через callback, декодирование строк, нативная карточка, таймер, снятие семи подписок и ZIP. Это не подтверждает выдачу чисел реальной машиной.
