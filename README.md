# L7 Cleanup 1.0.0

[Скачать отдельный APK](https://vorobyevie.github.io/l7-lab/L7Cleanup-1.0.0-debug.apk), 355 КБ, Android 9+. Пакет com.relix.l7cleanup; установка прежнего L7 Lab не требуется. Нет разрешений, интернета, карточки, телеметрии, модели речи или фоновых служб.

Использовать только на стоящей машине. При перезапусках приборов прекратить движение в безопасном месте и обратиться в сервис. Причина сбоя не установлена, устранение перезапусков этой утилитой не подтверждено.

1. Оставьте L7 Lab удалённым либо принудительно остановите его в настройках.
2. Нажмите «Удалить карточку L7 Lab». Отправляется одна транзакция удаления только com.relix.l7lab / LiLauncherCard в com.lixiang.sidebar 1.10.8 (110081), display 0. Новая карточка и обратный вызов не регистрируются. Сообщение о передаче запроса не доказывает завершение удаления из базы.
3. Необязательно: «Проверить заявки CarSupport» делает один get_requested, фильтрует семь прежних ID, не запрашивает значения машины и не добавляет заявки. Отсутствие ответа не трактуется как пустой список. Совпадение ID не устанавливает владельца заявки.
4. При наличии совпадений и необходимости освободить память заявок: «Открыть настройки CarSupport» → системная «Принудительно остановить» / «Остановить». В CarSupport 1.78 нет API выборочного удаления; завершение всего процесса затронет и другие его функции, включая HUD. «Стереть данные», «Очистить хранилище» и удаление CarSupport не нужны. Если кнопка остановки недоступна, нужен специалист CarModApps.

Проверка списка может запустить процесс CarSupport. После его остановки утилита не запускает его снова автоматически и не делает повторной проверки. Не нажимайте проверку после остановки без необходимости. Другие приложения могут зарегистрировать заявки заново после запуска CarSupport.

Проверены сборка, Android Lint и протокол на собственном строгом fixture в другом процессе эмулятора: удаление только нашей карточки, сохранность другой, единственный код удаления 3, отсутствие callback/add, закрытие соединения, однократное чтение списка, фильтрация/дедупликация семи ID, ошибки/неизвестные ответы без ложного успеха и корректный адрес страницы настроек. Реальные CarSupport и sidebar в эмулятор не устанавливались. Тестовые приложения и архивы владельца в публикацию не входят.

Основное приложение L7 Lab 0.7.3 не изменялось, его аппаратная блокировка сохранена. Предыдущие APK остаются в истории репозитория; их не следует устанавливать для новых автомобильных испытаний.
