# L7 Lab downloads

0.1.7: экспериментальный тест чтения семи сигналов через штатный OEM LASS под обычным UID L7 Lab. Обороты ДВС, ток и сырой SOC батареи, две температуры батареи и температуры переднего/заднего моторов. Реальный доступ на машине и единицы ещё нужно проверить.

Установить поверх предыдущей версии → «Диагностика» → «Показатели машины · проверка» → «Проверить показатели на 30 секунд» → Home для просмотра нашей карточки. После теста «Скопировать отчёт чтения»; последний снимок сохраняется в локальном отчёте, устаревшие цифры в карточке скрываются. Есть ручная остановка и возврат демо-счётчика.

Только семь get-вызовов раз в секунду в течение 30 секунд, без изменения автомобиля, выдачи привилегий и автозапуска. Локально проверены OEM Parcel ABI, mock в другом UID, отображение нативной карточки, недоступные/устаревшие данные и автоостановка. Это не подтверждает доступ на реальной машине.

Ранее владелец подтвердил нативную карточку и оптический HUD-тест на L7 2024 / firmware 7.4.1. Архив LiDashboard с машины получен и изучен; точный транспорт его защищённого кода не установлен.

Публикуются только собственные APK L7 Lab. Архивы машины, сторонние APK/JAR, их ресурсы и локальные test fixture не публикуются.
