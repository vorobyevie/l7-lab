# L7 Lab · Силовая установка

Скачать: https://vorobyevie.github.io/l7-lab/

Версия 0.2.2 меняет источники запаса хода: EV_WLTC_Mileage_HU и Fuel_WLTC_Mileage_HU из установленного CarService. CarSupport 1.78 сам читает второе поле. Прежние VehicleStatus_MSG_EVMileage/FuelMileage возвращали ноль в архиве автомобиля. Обозначение WLTC добавлено в панель приложения и карточку; сумма Σ показывается только при двух свежих доступных значениях. Настоящий ноль остаётся нулём, недоступные данные показаны прочерками.

Новые поля проверены локально с межпроцессными ответами, старые нулевые поля не подмешиваются. Численные значения новых источников ещё требуют проверки в машине. Адаптивная раскладка, 26 показателей, остановка из уведомления и предел семи запросов чтения в секунду сохранены.

Установить поверх текущего L7 Lab, открыть приложение и подождать 10 секунд. Вернуться на главный экран: карточка использует те же значения. При необходимости добавить её кнопкой «На главный экран». «Сохранить отчёт» пишет ZIP в Download/L7Lab.

В репозитории только собственный APK, страница скачивания и сведения о версии. Архивы владельца, сторонние программы, исследовательские fixture и ключи не публикуются. Контрольная сумма: SHA256SUMS.txt.
