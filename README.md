# L7 Lab · Силовая установка

Скачать: https://vorobyevie.github.io/l7-lab/

Версия 0.2.1 устраняет широкие внутренние поля карточки и окна приложения. Секции адаптируются к выделенным границам, сохраняя пропорции текста и рисунка. Проверены семь размеров/пропорций, включая высокую карточку и широкое окно.

На фото владельца 0.2.0 показывает 26/26 в автомобиле. Чтение, список сигналов и лимит семи запросов в секунду в этой версии не изменены. Единицы дополнительных показателей требуют проверки.

Установить поверх текущего L7 Lab, открыть приложение, вернуться на главный экран. При необходимости добавить карточку кнопкой «На главный экран». Обновление продолжается в фоне с уведомлением и кнопкой остановки. «Сохранить отчёт» пишет ZIP в Download/L7Lab.

В репозитории только собственный APK, страница скачивания и сведения о версии. Архивы владельца, сторонние программы, исследовательские fixture и ключи не публикуются. Контрольная сумма: SHA256SUMS.txt.
