# L7 Lab downloads

APK нашего приложения и статическая страница скачивания для L7 2024.

Текущая версия 0.1.3: экспериментальный адаптер карточки к штатному sidebar 1.10.8 (110081). Кнопки добавления и удаления действуют только на нашу карточку. Проверены ABI оригинального интерфейса, UI в отдельном процессе, обмен демо-счётчиком и формат Binder на тестовом сервисе. Фактическое отображение на машине ещё не подтверждено.

Установить поверх предыдущей версии, открыть «Карточка» → «Добавить на главный экран Li Auto», затем вернуться Home и проверить. Удаление — «Убрать нашу карточку с главного экрана».

Страница содержит только собственные APK. Архивы с машины, сторонние APK, декомпиляция и локальный тестовый host сюда не публикуются.
